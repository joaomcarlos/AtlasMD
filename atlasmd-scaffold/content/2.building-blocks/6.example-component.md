# Example Component

The `::example-component` is a demonstration component showing how to build MDC components with props, named slots, and default slots. Use it as a reference template when you create your own components in the renderer.

## 1. Example

::side-note
Example
::

::example-component{foo="hello" :items='["first item", "second item", "third item"]'}
#title
Example Component Title
#description
This is the description slot — it renders in blue italic.
::

## 2. Usage

### Block syntax (with YAML frontmatter)

```markdown
::example-component
---
foo: FOOO
:items: '["item1", "item2"]'
---
This text will be shown at the end of the component, after the title and description.

#title
This is just an example component

#description
This is a description of the example component.
::
```

### Inline syntax (with props on the tag)

```markdown
::example-component{foo='foo' :items='["item1", "item2"]'}
This text will be shown at the end of the component, after the title and description.

#title
This is just an example component

#description
This is a description of the example component.
::
```

## 3. Props

| Prop    | Type     | Default  | Purpose                       |
| ------- | -------- | -------- | ----------------------------- |
| `foo`   | string   | required | Demo string prop              |
| `bar`   | string   | `"baz"`  | Demo string prop with default |
| `items` | string[] | `[]`     | Demo array prop               |

## 4. Named Slots

| Slot           | Purpose                             |
| -------------- | ----------------------------------- |
| `#title`       | Renders in an `<h2>` with red text  |
| `#description` | Renders in blue italic              |
| default        | Renders after title and description |
