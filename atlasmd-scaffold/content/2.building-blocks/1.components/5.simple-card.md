# Simple Card

The `::simple-card` component renders a bordered card with a subtle background. Use it to group related content or highlight a block of text.

## Live Example

::simple-card
This is a simple card. It has a border, rounded corners, and a pale background. In dark mode the border and background shift to primary colors.
::

## Usage

```markdown
::simple-card
Your content here. Markdown is supported.
::
```

## Props

| Prop | Type | Default | Purpose |
|---|---|---|---|
| `style` | object | `{}` | Custom inline styles for the card |

## Source

`atlasmd-renderer/components/content/SimpleCard.vue` — a thin wrapper around a `.card` div with Docus theme tokens for border, background, and spacing.
