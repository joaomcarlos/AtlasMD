# Note

The `::note` component renders a highlighted callout box. Use it for important clarifications that readers must not miss.

## Live Example

::note
This is a note. The renderer styles it with a serif font, a pale background, and an accent left rule so it stands out from body text.
::

## Usage

```markdown
::note
Your text here. Markdown is supported — **bold**, *italic*, `code`, links.
::
```

## Source

`atlasmd-renderer/components/content/Note.vue` — a simple wrapper that renders an MDCSlot inside a `.note` div. Styling comes from `atlasmd-renderer/assets/css/base.scss`.
