# Field

The `::field` component renders a single API field definition with name, type, required marker, and description. Use it to document request/response fields, config keys, or data model columns.

## 1. Live Example

::field{name="amount" type="integer" required="true"}
#description
The payment amount in minor units (cents). Must be a positive integer.
::

::field{name="currency" type="string" required="true"}
#description
ISO 4217 currency code (e.g. `EUR`, `USD`).
::

::field{name="reference" type="string"}
#description
Optional merchant reference for the payment.
::

## 2. Usage

```markdown
::field{name="amount" type="integer" required="true"}
#description
The payment amount in minor units (cents).
::
```

You can also use the default slot instead of the `#description` named slot:

```markdown
::field{name="amount" type="integer" required="true"}
The payment amount in minor units (cents).
::
```

## 3. Props

| Prop       | Type    | Default  | Purpose                                          |
| ---------- | ------- | -------- | ------------------------------------------------ |
| `name`     | string  | required | Field name                                       |
| `type`     | string  | required | Field type (e.g. `string`, `integer`, `boolean`) |
| `required` | boolean | `false`  | Show red asterisk next to the field name         |

## 4. Source

`atlasmd-renderer/components/content/Field.vue` — renders the field name, type, required marker, and description in a flex row. Supports a `#subfields` named slot for nested fields.
