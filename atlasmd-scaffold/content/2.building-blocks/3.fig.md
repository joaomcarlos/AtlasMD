# Fig

The `::fig` component renders an image with optional caption, dark/light mode variants, and click-to-zoom modal. Use it instead of standard markdown images when you need dark mode support or zoom.

## 1. Live Example

::fig
---
src: /favicon-32.png
caption: "Figure 1: The AtlasMD favicon (32x32). Click to zoom."
width: "64px"
---
::

## 2. Usage

### Simplest — light mode only

```markdown
::fig
---
src: /path/to/light/mode/image.png
---
::
```

### With caption and width

```markdown
::fig
---
src: /path/to/image.png
caption: "Image caption"
width: "600px"
---
::
```

### With dark mode variant

```markdown
::fig
---
src: /path/to/light/image.png
darkmodeSrc: /path/to/dark/image.png
---
::
```

### With separate zoom (modal) images

```markdown
::fig
---
src: /path/to/light/inline.png
srcModal: /path/to/light/modal.png
darkmodeSrc: /path/to/dark/inline.png
darkmodeSrcModal: /path/to/dark/modal.png
---
::
```

### Disable zoom

```markdown
::fig
---
src: /path/to/image.png
allowZoom: false
---
::
```

## 3. Props

| Prop                | Type    | Default  | Purpose                                            |
| ------------------- | ------- | -------- | -------------------------------------------------- |
| `src`               | string  | required | Light mode inline image path (from `public/`)      |
| `darkmodeSrc`       | string  | —        | Dark mode inline image path                        |
| `caption`           | string  | `""`     | Caption text below the image                       |
| `width`             | string  | `"auto"` | CSS width for the inline image                     |
| `srcModal`          | string  | —        | Light mode zoom modal image (falls back to `src`)  |
| `darkmodeSrcModal`  | string  | —        | Dark mode zoom modal image                         |
| `allowZoom`         | boolean | `true`   | Enable click-to-open zoom modal                    |
| `keepTransparentBg` | boolean | `false`  | Keep modal background transparent instead of solid |

## 4. Source

`atlasmd-renderer/components/content/Fig.vue` — handles dark/light mode switching via `useColorMode()`, refines image URLs for baseURL subpaths, and renders a full-screen modal on click.
