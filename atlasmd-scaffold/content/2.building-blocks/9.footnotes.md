# Footnotes

AtlasMD supports markdown footnotes via Nuxt Content. Footnotes render as superscript numbers in the body text and a numbered references list at the bottom of the page.

## 1. Example

::side-note
Example
::

AtlasMD uses Docus as its documentation framework[^1]. The renderer packages Nuxt, Docus, and custom components into a Docker image[^2] that consumer projects mount content into.

## 2. Usage

### Inline footnote

```markdown
AtlasMD uses Docus[^1] as its framework.

[^1]: [Docus](https://docus.dev) — documentation framework built on Nuxt.
```

### Multi-line footnote

```markdown
[^2]: First line of the footnote.
    Second line — indent with 4 spaces to continue the same footnote.
```

## 3. Rendering

Nuxt Content extracts footnote definitions into a hidden `<h2 id="footnote-label">` element and renders a numbered `<ol>` list below it. The `base.scss` stylesheet styles the references list and back-references.

## 4. Source

Footnote parsing is handled by Nuxt Content's markdown parser. Styling is in `atlasmd-renderer/assets/css/base.scss` under the `h2#footnote-label + ol` selector.
