# Docus Built-in Components

AtlasMD extends [Docus](https://docus.dev), which provides built-in MDC components for landing pages and navigation. These components are available without any additional setup.

## 1. Block Hero

::side-note
Example
::

Renders a hero section with a call-to-action button, optional secondary link, and a terminal snippet. Used on the home page (`0.index.md`).

::block-hero
---
cta:

- Get Started
- /getting-started

secondary:

- View on GitHub
- https://github.com/joaomcarlos/AtlasMD

snippet:

- git clone https://github.com/joaomcarlos/AtlasMD.git
- cd AtlasMD/atlasmd-scaffold
- docker compose up

---
#title
Block Hero Title
#description
This is a block hero. It shows a title, description, a primary CTA button, a secondary link, and a click-to-copy terminal snippet on the right.
::

### Usage

```markdown
::block-hero
---
cta:

- Button Label
- /route/path

secondary:

- Secondary Label
- https://external-link.example.com

snippet:

- command one
- command two

---
#title
Your Title
#description
Your description.
::
```

## 2. Card Grid

Renders a responsive grid of cards. Each card can have an icon, title, and description.

::card-grid
#title
Card Grid Title
#root
:ellipsis{left=0px width=40rem top=10rem blur=140px}
#default
  ::card{icon=heroicons:academic-cap}
  #title
  Card One
  #description
  First card description.
  ::

  ::card{icon=heroicons:cog-6-tooth}
  #title
  Card Two
  #description
  Second card description.
  ::
::

### Usage

```markdown
::card-grid
#title
Card Grid Title
#default
  ::card{icon=heroicons:academic-cap}
  #title
  Card One
  #description
  First card description.
  ::
::
```

## 3. Card

Renders a single card with an icon, title, and description. Use inside `::card-grid` or standalone.

::card{icon=heroicons:light-bulb}
#title
Standalone Card
#description
This card is not inside a card grid. It still renders with an icon, title, and description.
::

### Usage

```markdown
::card{icon=heroicons:light-bulb}
#title
Card Title
#description
Card description.
::
```

## 4. Ellipsis

Renders a decorative blurred gradient. Use for visual flair on landing pages.

:ellipsis{right=0px width=75% blur=150px}

### Usage

```markdown
:ellipsis{right=0px width=75% blur=150px}
```

## 5. Icons

Docus integrates [Iconify](https://iconify.design). Reference any icon with the `icon=` prop or the `:icon-name` syntax:

- `heroicons:academic-cap`
- `heroicons:cog-6-tooth`
- `mdi:code-tags`
- `heroicons:light-bulb`

Browse available icon sets at [icones.js.org](https://icones.js.org).
