# Side Note

The `::side-note` component renders text in the marginalia column — the narrow left margin of the technical manual layout. Use it for ancillary commentary, citations, or clarifications that support the main text without interrupting its flow.

## 1. Live Example

::side-note
This text appears in the left margin. It uses a serif font and a bordered box so readers can distinguish it from the main column.
::

The main body text continues here. The side note sits in the margin to the left, aligned vertically with this paragraph.

## 2. Usage

```markdown
::side-note
Your marginal text here.
::
```

::note
Side notes rely on the CSS grid layout in `base.scss` (1.5in margin | 5.5in content | 1fr). On narrow screens the marginalia column collapses and side notes render inline.
::

## 3. Source

`atlasmd-renderer/components/content/SideNote.vue` — renders an MDCSlot inside a `.marginalia` div. Styling comes from `atlasmd-renderer/assets/css/base.scss`.
