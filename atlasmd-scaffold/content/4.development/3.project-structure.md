# Project Structure

```
AtlasMD/
  atlasmd-renderer/      Rendering engine (Nuxt + Docus)
    app.config.ts        Docus config (title, socials, footer)
    nuxt.config.ts       Nuxt config (routes, prerender, theme)
    tokens.config.ts     Color palette and Docus theme tokens
    components/          Vue components (Logo, content components)
    plugins/             Client plugins (scroll-behavior, sidebar-follow)
    assets/css/          Base styles and image CSS
    support/             Link checker and fixer scripts
    Dockerfile           Builds the rendering image
    docker-compose.yml   Compose for standalone development
  atlasmd-scaffold/      Template for consumer projects
    content/             Markdown documentation (this guide)
      1.getting-started/ Overview and integration guide
      2.building-blocks/ Live-rendered component reference
        1.components/    One page per MDC component
      3.configuration/   Environment variables, conventions, customization
      4.development/     Building, running, project structure
    public/              Favicons, logos, static images
    docker-compose.yml   Compose template for consumer projects
  README.md              Integration instructions
```

## Renderer vs Scaffold

| Folder              | Contains                 | Purpose                        |
| ------------------- | ------------------------ | ------------------------------ |
| `atlasmd-renderer/` | JS project, Dockerfile   | Builds the Docker image        |
| `atlasmd-scaffold/` | Markdown content, assets | Template for consumer projects |

Consumer projects copy `atlasmd-scaffold/` and mount its `content/` and `public/` into the image built from `atlasmd-renderer/`.
