# Project Structure

AtlasMD has two subprojects: the renderer (builds the Docker image) and the scaffold (template for consumer projects). The renderer contains all JavaScript, Vue components, and CSS. The scaffold contains only markdown content and static assets.

- **atlasmd-renderer/** — Rendering engine (Nuxt + Docus)
  - **config.ts** — TOML config loader (reads `/app/config.toml` at startup)
  - **config.value.json** — Generated JSON config (written by `config.ts`, read by `app.config.ts`)
  - **app.config.ts** — Docus runtime config (title, socials, footer — from `config.value.json`)
  - **nuxt.config.ts** — Nuxt config (routes, prerender, theme)
  - **tokens.config.ts** — Color palette and Docus theme tokens
  - **components/** — Vue components (Logo, content components)
  - **plugins/** — Client plugins (scroll-behavior, sidebar-follow)
  - **assets/css/** — Base styles and image CSS
  - **support/** — Build-time patches (pinceau SSR hydration fix)
  - **Dockerfile** — Builds the rendering image
- **atlasmd-scaffold/** — Template for consumer projects
  - **content/** — Markdown documentation (this guide)
    - **1.getting-started/** — Overview and integration guide
    - **2.building-blocks/** — Live-rendered component reference (one page per MDC component)
    - **3.configuration/** — Config file, conventions, customization
    - **4.development/** — Building, running, project structure
    - **5.release-notes/** — Published image versions (hidden from navigation)
  - **public/** — Favicons, logos, static images
  - **config.toml** — Consumer configuration (title, socials, footer)
  - **compose.yml** — Compose template for consumer projects
- **README.md** — Project overview and integration instructions

## 1. Renderer vs Scaffold

::side-note
Renderer vs scaffold
::

| Folder              | Contains                 | Purpose                        |
| ------------------- | ------------------------ | ------------------------------ |
| `atlasmd-renderer/` | JS project, Dockerfile   | Builds the Docker image        |
| `atlasmd-scaffold/` | Markdown content, assets | Template for consumer projects |

Consumer projects copy `atlasmd-scaffold/` and mount its `content/` and `public/` into the image built from `atlasmd-renderer/`.
