# Building the Image

## Prerequisites

- Docker

## Build

```bash
cd atlasmd-renderer
docker compose build
```

This produces the `atlasmd:latest` image.

## What the Dockerfile Does

```dockerfile
ARG APP_VERSION

FROM node:lts-alpine

WORKDIR /app
COPY package.json yarn.lock ./

RUN --mount=type=cache,target=/root/.yarn YARN_CACHE_FOLDER=/root/.yarn yarn install

COPY . .

# content/ and public/ are expected to be volume-mounted at runtime
RUN mkdir -p content public

ENV APP_VERSION=${APP_VERSION}
ENV PORT=3003
CMD ["yarn", "run", "dev"]
```

The image installs dependencies and copies the renderer source. The `content/` and `public/` directories are created as empty mount points — consumer projects fill them at runtime via volume mounts.

## Dev Mode

The image runs Nuxt in dev mode (`nuxi dev`). This is intentional: Docus prerenders content at build time, but content is mounted at runtime. Dev mode serves runtime-mounted content without requiring a rebuild.

## Rebuilding After Changes

When you change the renderer source (components, config, CSS, plugins), rebuild the image:

```bash
cd atlasmd-renderer
docker compose build
```

Consumer projects pick up the new image on their next `docker compose up`.
