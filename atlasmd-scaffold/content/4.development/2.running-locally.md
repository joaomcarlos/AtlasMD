# Running Locally

AtlasMD runs in dev mode inside a Docker container. The scaffold's compose file pulls the image and mounts content, public, and config at runtime.

## 1. With the Scaffold

The scaffold in this repository runs AtlasMD documenting itself:

::snippet{:content='["cd atlasmd-scaffold", "docker compose up"]'}
::

Open `http://localhost:47145`.

## 2. With Docker Watch

::side-note
Docker watch
::

For live content reloading during development:

::snippet{:content='["cd atlasmd-scaffold", "docker compose up", "docker compose watch"]'}
::

Docker watch syncs `content/` and `public/` changes into the running container without restart.

## 3. From a Consumer Project

::snippet{:content='["# In the consumer project root", "docker compose up atlasmd-docs"]'}
::

The service name `atlasmd-docs` comes from the scaffold's `compose.yml`. Consumer projects can rename the service — use whatever name they define.

## 4. Ports

::side-note
Port mapping
::

| Port  | Container | Purpose                            |
| ----- | --------- | ---------------------------------- |
| 47145 | 47145     | Web server (HTTP)                  |
| 47146 | 4000      | HMR websocket (content hot reload) |

The scaffold sets `PORT=47145` in the compose environment so the Nuxt dev server listens on 47145 inside the container. The HMR websocket always uses container port 4000. Consumer projects can map different host ports — change the left side of the port mapping in `compose.yml`.
