# Running Locally

## With the Scaffold

The scaffold in this repository runs AtlasMD documenting itself:

```bash
cd atlasmd-scaffold
docker compose up
```

Open `http://localhost:47145`.

## With Docker Watch

For live content reloading during development:

```bash
cd atlasmd-scaffold
docker compose up
docker compose watch
```

Docker watch syncs `content/` and `public/` changes into the running container without restart.

## From a Consumer Project

```bash
# In the consumer project root
docker compose up atlasmd-docs
```

The service name `atlasmd-docs` comes from the scaffold's `docker-compose.yml`. Consumer projects can rename the service — use whatever name they define.

## Ports

| Port  | Container | Purpose                            |
| ----- | --------- | ---------------------------------- |
| 47145 | 47145     | Web server (HTTP)                  |
| 47146 | 4000      | HMR websocket (content hot reload) |

Consumer projects can map different host ports. The container ports (3003, 4000) stay fixed.
