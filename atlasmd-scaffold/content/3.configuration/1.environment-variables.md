# Environment Variables

AtlasMD reads configuration from environment variables at container startup.

## Variables

| Variable                    | Default                      | Purpose                                                    |
| --------------------------- | ---------------------------- | ---------------------------------------------------------- |
| `ATLAS_TITLE`               | `Atlas`                      | Project name in header and browser title                   |
| `ATLAS_GITLAB_URL`          | —                            | GitLab repository URL for header social link; omit to hide |
| `ATLAS_GITLAB_LABEL`        | `View the Gitlab repository` | Label for the GitLab social link                           |
| `ATLAS_SLACK_URL`           | —                            | Slack channel URL for header social link; omit to hide     |
| `ATLAS_SLACK_LABEL`         | `Message us on Slack`        | Label for the Slack social link                            |
| `ATLAS_FOOTER_CREDITS_TEXT` | —                            | Footer credits text; omit to hide                          |
| `ATLAS_FOOTER_CREDITS_URL`  | —                            | Footer credits link URL                                    |
| `ATLAS_FOOTER_CREDITS_ICON` | `heroicons-outline:cloud`    | Footer credits icon                                        |
| `ATLAS_FOOTER_TEXT`         | —                            | Footer text link label; omit to hide                       |
| `ATLAS_FOOTER_TEXT_URL`     | —                            | Footer text link URL                                       |
| `ATLAS_LOGO_LIGHT`          | `/logo-light.png`            | Light mode logo path (served from `public/`)               |
| `ATLAS_LOGO_DARK`           | `/logo-dark.png`             | Dark mode logo path                                        |
| `ATLAS_LOGO_DARK_BG`        | `/logo-dark-bg.png`          | Dark mode logo with background                             |
| `ATLAS_BASE_URL`            | `/`                          | Base URL path (for GitLab Pages subpaths)                  |
| `APP_VERSION`               | —                            | Version chip next to title                                 |
| `CI_PAGES_URL`              | —                            | GitLab Pages URL; overrides `ATLAS_BASE_URL` when set      |
| `PORT`                      | `3003`                       | Port the dev server listens on                             |

## Example

```yaml
environment:
  - ATLAS_TITLE=MyProject
  - ATLAS_GITLAB_URL=https://git.example.com/group/my-project
  - ATLAS_GITLAB_LABEL=View MyProject on GitLab
  - ATLAS_SLACK_URL=https://example.slack.com/archives/C123
  - ATLAS_FOOTER_CREDITS_TEXT=MyCompany
  - ATLAS_FOOTER_CREDITS_URL=https://example.com
  - ATLAS_FOOTER_TEXT=Built by MyCompany
  - ATLAS_FOOTER_TEXT_URL=https://example.com
  - ATLAS_LOGO_LIGHT=/my-logo-light.png
  - ATLAS_LOGO_DARK=/my-logo-dark.png
  - ATLAS_LOGO_DARK_BG=/my-logo-dark-bg.png
  - APP_VERSION=1.0.0
```

## GitLab Pages

When deploying to GitLab Pages, set `CI_PAGES_URL`. AtlasMD derives the base path from it so all routes and assets resolve correctly under the pages subpath.

The `CI_PAGES_URL` variable is automatically set by GitLab CI. Do not set it manually in your compose file.
