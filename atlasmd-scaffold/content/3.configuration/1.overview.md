# Configuration

AtlasMD reads consumer configuration from a TOML file mounted into the container at `/app/config.toml`. Place `config.toml` next to your `content/` and `public/` folders and mount it in your compose file.

Only CI/build-driven values stay as environment variables: `CI_PAGES_URL` (set automatically by GitLab CI), `APP_VERSION` (build arg), and `PORT`.

## 1. File

::side-note
The container reads this file at `/app/config.toml`. The compose file mounts it there at startup.
::

The scaffold ships a working `config.toml` at `atlasmd-scaffold/config.toml` — copy it and edit the values for your project. Every consumer-configurable setting lives in that file.

## 2. Fields

| Field                 | Default                   | Purpose                                                                                 |
| --------------------- | ------------------------- | --------------------------------------------------------------------------------------- |
| `title`               | `AtlasMD`                 | Project name in header and browser title                                                |
| `baseUrl`             | `/`                       | Base URL path (for GitLab Pages subpaths); `CI_PAGES_URL` overrides this at deploy time |
| `socials[].url`       | —                         | Social link URL; add one `[[socials]]` block per link                                   |
| `socials[].label`     | —                         | Label for the social link                                                               |
| `socials[].icon`      | —                         | Iconify icon name (e.g. `simple-icons:gitlab`, `simple-icons:slack`)                    |
| `footer.credits.text` | —                         | Footer credits text; omit to hide                                                       |
| `footer.credits.url`  | —                         | Footer credits link URL                                                                 |
| `footer.credits.icon` | `heroicons-outline:cloud` | Footer credits icon                                                                     |
| `footer.text.label`   | —                         | Footer text link label; omit to hide                                                    |
| `footer.text.url`     | —                         | Footer text link URL                                                                    |

## 3. Logos

Logos are convention-based. Drop these files into `public/` and AtlasMD picks them up automatically — no configuration needed:

| Theme state               | Filename                |
| ------------------------- | ----------------------- |
| Light mode                | `logo-light-mode.png`   |
| Dark mode                 | `logo-dark-mode.png`    |
| Dark mode with background | `logo-dark-mode-bg.png` |

## 4. Environment Variables

| Variable       | Default | Purpose                                                               |
| -------------- | ------- | --------------------------------------------------------------------- |
| `APP_VERSION`  | —       | Version chip next to title (build arg)                                |
| `CI_PAGES_URL` | —       | GitLab Pages URL; set automatically by GitLab CI; overrides `baseUrl` |
| `PORT`         | `3003`  | Port the dev server listens on                                        |

## 5. GitLab Pages

When deploying to GitLab Pages, `CI_PAGES_URL` is set automatically by GitLab CI. AtlasMD derives the base path from it so all routes and assets resolve correctly under the pages subpath. Do not set it manually.
