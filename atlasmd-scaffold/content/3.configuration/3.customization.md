# Customization

## Logos

Logos are env-var driven. Place your logo files in `public/` and set the paths via environment variables:

```yaml
ATLAS_LOGO_LIGHT=/my-logo-light.png
ATLAS_LOGO_DARK=/my-logo-dark.png
ATLAS_LOGO_DARK_BG=/my-logo-dark-bg.png
```

The `Logo.vue` component reads from `runtimeConfig.public` and renders the correct logo based on the active theme.

## Theme and Colors

Theme tokens live in `atlasmd-renderer/tokens.config.ts`. To change colors, typography, or spacing, modify that file and rebuild the image.

::note
Theme changes affect all consumer projects. If you need project-specific theming, fork the renderer or open a discussion about adding env-var-driven theme overrides.
::

## Social Links

The Slack social link is shared across all AtlasMD projects. The GitLab link is env-var driven — each consumer passes its own repository URL.

To add or remove social links, edit `atlasmd-renderer/app.config.ts`.

## Footer

The footer is shared across all AtlasMD projects. To change footer text or links, edit `atlasmd-renderer/app.config.ts`.

## CSS

Base styles live in `atlasmd-renderer/assets/css/`. The image CSS handles `<DarkLightModeImage>` rendering. The base SCSS handles typography, tables, marginalia, and layout.

To add project-specific CSS, consumer projects can include custom components in their content using MDC syntax.
