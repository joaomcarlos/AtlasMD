# Release Notes

AtlasMD publishes a new Docker image to GHCR on every push to main that changes the renderer or the publish workflow. Each image gets two tags: `:latest` and `:sha-<short>`. This page lists every published version and the changes in it.

Newest version at the top. Each version groups changes by category.

## sha-484384f

Multi-platform image build and favicon support.

### Features

- Favicons for the scaffold (`favicon.ico`, `favicon-16.png`, `favicon-32.png`)
- `atlasmd-icons` skill that generates all logos and favicons from one source image

### Fixes

- Icon skill now produces transparent backgrounds for all three logo variants

### Infrastructure

- Build multi-platform image (`linux/amd64`, `linux/arm64`) for GHCR
- All AI skills now use `uv run` for dependency management

## sha-9f91400

First published image. Includes the rendering engine, config system, branding defaults, and component library.

### Features

- Nuxt + Docus rendering engine with Docker support
- TOML config file for consumer settings (`title`, `socials`, `footer`, `baseUrl`)
- AtlasMD self-branding defaults (footer credits, GitHub social link)
- MDC content components: `note`, `side-note`, `fig`, `field`, `simple-card`, `example-component`, mermaid diagrams
- Landing page with hero, terminal snippet, and section card grid

### Fixes

- Pinceau SSR hydration mismatch — replaced random `nanoid(6)` variant classes with deterministic hashes
- Config load problems — split config loading to keep `node:fs` out of the client bundle
- `base-url` typo in config — corrected to `baseUrl`

### Infrastructure

- GitHub Actions workflow that publishes the image to `ghcr.io/joaomcarlos/atlasmd` on push to main
- Renumbered scaffold ports from `8770`/`8771` to `47145`/`47146`
- Removed renderer-local dev tooling (`justfile`, `.envrc`, `docker-compose.yml`)
